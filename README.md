# KITTI Object Detection with YOLOv8

This repository provides a complete pipeline for training and evaluating a **YOLOv8** object detection model using the **KITTI Vision Benchmark Dataset**. The project focuses on detecting three primary classes: **Cars, Pedestrians, and Cyclists**.

## Project Structure

```text
.
├── data/
│   ├── kitti_raw/          # Raw KITTI dataset (Manual Setup Required)
│   └── kitti_yolo/         # Converted dataset (Generated by script)
├── runs/                   # Training logs, weights, and evaluation plots
├── scripts/
│   ├── convert_kitti_to_yolo.py  # Data preprocessing & splitting
│   ├── train_yolo.py             # Model training script
│   ├── print_metrics.py          # Standard mAP and PR curve generation
│   ├── difficulty_eval.py        # KITTI-specific difficulty analysis
│   └── inference_val.py          # Qualitative result generation
└── README.md
```

## Setup & Installation

### 1. Environment
Ensure you are using **NumPy 1.x** to avoid compatibility issues with the standard vision stack.

```bash
pip install "numpy<2" "ultralytics" "matplotlib" "opencv-python<4.10" "protobuf<5"
```

### 2. Dataset Preparation
The raw KITTI data is not included. 
1. Download **Left color images** and **Training labels** from the [KITTI Website](https://www.cvlibs.net/datasets/kitti/eval_object.php?obj_benchmark=2d).
2. Place the raw files in `data/kitti_raw/training/image_2` and `data/kitti_raw/training/label_2`.
3. Run the conversion script to prepare the YOLO format:
   ```bash
   python scripts/convert_kitti_to_yolo.py
   ```

## Execution Pipeline

### Step 1: Training
Train the YOLOv8 Nano baseline for 20 epochs. This uses transfer learning from weights pre-trained on COCO.
```bash
python scripts/train_yolo.py
```
*Outputs: Weights and training logs will be in `runs/yolo_kitti_baseline/`.*

### Step 2: Formal Evaluation
Generate the standard Precision-Recall curves and Average Precision (AP) scores.
```bash
python scripts/print_metrics.py
```

### Step 3: KITTI Difficulty Analysis
Compute AP specifically for **Easy, Moderate, and Hard** levels based on bounding box height, occlusion, and truncation.
```bash
python scripts/difficulty_eval.py
```

### Step 4: Qualitative Visualization
Run inference on a random sample of 10 validation images to visualize successful detections and failure cases.
```bash
python scripts/inference_val.py
```

## Evaluation Protocol

Performance is measured using the standard KITTI requirements:

| Class | IoU Threshold | Difficulty Levels |
| :--- | :--- | :--- |
| **Car** | 0.7 | Easy, Moderate, Hard |
| **Pedestrian** | 0.5 | Easy, Moderate, Hard |
| **Cyclist** | 0.5 | Easy, Moderate, Hard |

### Difficulty Definitions:
* **Easy:** Min. height: 40px, Fully visible, Max. truncation: 15%.
* **Moderate:** Min. height: 25px, Partly occluded, Max. truncation: 30%.
* **Hard:** Min. height: 25px, Difficult to see, Max. truncation: 50%.

## Results Analysis
After running the pipeline, refer to the following files in the `runs/` directory for your report:
* `confusion_matrix.png`: Analyze class-to-class confusion.
* `BoxPR_curve.png`: Precision-Recall trade-offs.
* `results.csv`: Epoch-by-epoch training statistics.
* `inference/kitti_random_samples/`: Visual overlays for qualitative discussion.
